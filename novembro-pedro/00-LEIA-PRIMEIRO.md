# Novembro 2026 — acompanhamento do Pedro Lage

Pasta de memória do mês. Quem for retomar o acompanhamento (eu, Claude, ou o próprio Pedro) começa por aqui.

## Como usar esta pasta

| Arquivo | Para que serve | Quando atualizar |
|---|---|---|
| `00-LEIA-PRIMEIRO.md` | Contexto fixo do mês: ofertas, datas, quem é quem, regras | Só quando a ficha ou o plano mudar |
| `01-plano-de-execucao.md` | Ordem de prioridade, marcos e o jeito mais eficiente de fazer cada tipo de tarefa | Quando mudar prioridade |
| `02-calendario.md` | Dia a dia de 29/10 a 02/12: o que vence, o que chega dos outros, reuniões | Quando um prazo mudar |
| `03-status.md` | Placar: feito / fazendo / falta, tarefa por tarefa | **Todo dia**, no fim do expediente |
| `04-decisoes-e-pendencias.md` | Perguntas para o Vitor, riscos, decisões tomadas | Sempre que surgir ou fechar uma |
| `diario/AAAA-MM-DD.md` | Registro do dia: o que foi feito, o que travou, o que fica para amanhã | Todo dia |
| `fontes/` | Exportação completa das tarefas do Alliance OS (29/10) | Só se reexportar |

**Regra combinada:** nada é executado (Shopify, Alliance OS, disparos, publicações) sem o ok do Pedro no chat.

**Rotina diária sugerida:**
1. Manhã (antes da daily das 09h40): ler `03-status.md` + o dia em `02-calendario.md` e fechar a lista do dia.
2. Durante o dia: executar uma tarefa por vez, passo a passo.
3. Fim do dia: atualizar `03-status.md` e escrever `diario/<data>.md`.
